# 儿童汽车认知与拍照识别 App 后端服务 (car-kids-server V1.2)

基于 **Python + FastAPI + SQLite + Mac 本地文件存储** 构建，面向 3—5 岁儿童及家长的汽车认知与拍照识别后端服务。

## 核心特性

1. **双维汽车图鉴**：
   - **按车辆类型浏览**：家用车、越野车、工程车（挖掘机、装载机、推土机、起重机、压路机、混凝土搅拌车）、货运车辆、公共交通、特种车辆、摩托及其他；支持多对多分类关联。
   - **按品牌层级浏览**：遵循 `品牌/子品牌 → 产品线（可选，如比亚迪王朝/海洋）→ 车系（如奔驰 E 级、宝马 3 系）→ 具体车型/年款/配置（如 2024款 E 300 L）` 四级结构。
2. **三级拍照识车匹配与待审核入库**：
   - 第三方识别 Provider 适配器隔离，规范化识别候选后按 **品牌 → 产品线/车系 → 具体车型** 及各级别名逐级比对。
   - 命中已审核具体车型或车系直接返回（不会把车系级识别结果胡乱下推成某个具体配置）。
   - 未命中且信息可信时自动创建对应层级 `pending_review` 草稿；信息不足时写入 `recognition_inbox`，绝不向儿童端直接展示未审核内容。
3. **真实图片优先与隐私保护**：
   - 优先返回 `real_photo`（真实车辆实拍图），`synthetic_model`（仿真 3D 模型）强制标识。
   - 拍照上传文件经 Pillow 解码校验后仅在识别期间使用，默认不永久留存原图，不暴露 Mac 本地磁盘绝对路径。

## 启动方式

```bash
cd car-kids-server
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env

# 启动 FastAPI 服务（首次启动自动建表并导入 P0 种子数据与内置合规纯色示例图）
uvicorn app.main:app --host 127.0.0.1 --port 8088 --reload
```

## 安全与合规说明

- **敏感配置隔离**：请在本地 `.env` 文件中配置真实的 `RECOGNITION_API_KEY` 与高强度随机 `ADMIN_ACCESS_TOKEN`，`.env`、`data/*.db*` 与 `storage/` 均已加入 `.gitignore`，切勿提交至公开代码仓库。
- **内置合规图库**：首次启动时，`app/db/seed.py` 会自动生成纯色圆角示意卡片，不含任何受第三方版权保护的实拍图片或商业商标原图。
- **非商业科研声明**：本项目仅用于学术研究与教学演示，禁止用于任何商业用途。
